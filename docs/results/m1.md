## Analyze and improve

- The first full run of the audit found `pip 26.1.1` in the virtual environment with two
  advisories (PYSEC-2026-196, PYSEC-2026-3721); `make setup` and `.tmp/check.sh` now upgrade pip
  first, and the audit is clean.
- A first version of the demo test indexed scenarios by caller name and two scenarios share the
  caller `frontend`; the test now indexes by position.
- `mypy --strict` flagged that spec values reach `validate_label` untyped; the validator now
  takes `object` and checks the type itself.
- The register script failed on a second run in principle (`entry create` on an existing entry);
  it now treats "already exists" as success, and the kind job runs it twice.
